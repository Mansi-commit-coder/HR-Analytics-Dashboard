# HR Analytics Dashboard

## Project Overview
The HR Analytics project focuses on analyzing employee data to understand workforce trends, employee attrition, and other key human resource metrics. The goal is to transform raw HR data into meaningful insights that can support data-driven HR decisions.

## Objectives
- Analyze employee attrition and workforce distribution.
- Understand employee demographics and job roles.
- Identify trends related to employee satisfaction and retention, where data is available.
- Track key HR performance indicators (KPIs).
- Provide actionable insights to support HR decision-making.

## Tools and Technologies
- **Power BI:** Interactive dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** KPI calculations and measures, if used.
- **Microsoft Excel:** Data preparation and initial analysis, if used.

## Key HR Metrics
- Total Employees
- Attrition Count and Attrition Rate
- Active Employee Count
- Employee Distribution by Department
- Employee Distribution by Job Role
- Workforce Demographics
- Job Satisfaction or Employee Satisfaction, if available

## Project Workflow
1. Import the HR dataset.
2. Clean and transform the data.
3. Create calculated measures and KPIs.
4. Analyze workforce trends and employee attrition.
5. Build an interactive dashboard.
6. Identify insights that can help improve employee retention and HR planning.
